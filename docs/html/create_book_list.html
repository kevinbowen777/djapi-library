Add book list¶

Template for adding a list of books to djapi-library Django application

book = Book.objects.create(
    title="",
    author="",
    pages=xxx,
    publisher="",
    pubdate="",
    price="",
    isbn="",
    isbn="",
)

Instructions¶

In the application directory, run the following command:

$ python manage.py shell_plus
